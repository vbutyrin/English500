АНГЛИЙСКИЙ 500 — КАК ПОЛУЧИТЬ УСТАНОВОЧНЫЙ APK

В архиве находится полноценный исходный проект Android и автоматическая сборка GitHub Actions.
Готовый установочный файл НЕ включён в архив: в текущей среде отсутствует Android SDK и нет доступа к загрузке SDK.

ВАРИАНТ 1. GitHub Actions (без Android Studio)
1. Создайте новый репозиторий GitHub, например English500.
2. Загрузите в корень репозитория СОДЕРЖИМОЕ папки English500, включая скрытую папку .github (там лежит сборочный сценарий).
3. Откройте вкладку Actions → «Сборка Android APK» → Run workflow.
   Если автоматическая сборка уже запущена после первой загрузки, достаточно дождаться её окончания.
4. Откройте завершённый запуск и скачайте архив «Английский-500-APK» в разделе Artifacts.
5. Извлеките app-debug.apk и откройте его на Android для установки.
6. При необходимости разрешите установку приложений из данного источника.

ВАРИАНТ 2. Android Studio
1. Откройте папку English500 в Android Studio.
2. Установите Android SDK Platform 35 и JDK 17 при запросе.
3. Build → Build Bundle(s) / APK(s) → Build APK(s).
4. APK находится в app/build/outputs/apk/debug/app-debug.apk.
