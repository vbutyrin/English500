# Английский за 500 слов — приложение для Android

Рабочая первая версия: 500 английских слов в 20 категориях, 40 готовых фраз, переворачиваемые карточки, озвучивание средствами Android TextToSpeech, режимы новых слов и повторения, тест из 10 вопросов и сохранение прогресса на устройстве.

## Сборка APK в Android Studio

1. Установите Android Studio (с Android SDK Platform 35 / Build Tools) и JDK 17.
2. Откройте папку `English500` в Android Studio (File → Open).
3. Дождитесь Gradle Sync (при первом запуске нужен интернет для загрузки Gradle/Android Gradle Plugin).
4. Выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
5. Файл будет создан по пути `app/build/outputs/apk/debug/app-debug.apk`.
6. Перенесите APK на телефон Android и установите. Может потребоваться разрешить установку из выбранного источника.

При желании можно сразу открыть `app/src/main/assets/index.html` в браузере на компьютере. Android-приложение использует тот же интерфейс в WebView, работает автономно, а слова озвучиваются через системный синтез речи. Для звуковых данных английского голоса на некоторых устройствах может потребоваться предварительно установить голосовой пакет Android.

**Примечание:** проект содержит исходный код и ресурсы, но готовый APK здесь не собирался и не проходил проверку на реальном Android-устройстве.

## Автоматическая сборка APK через GitHub Actions

В `.github/workflows/build-apk.yml` настроена сборка `app-debug.apk` с Java 17, Android SDK 35 и Gradle 8.10.2. Загрузите содержимое проекта в репозиторий GitHub, затем откройте Actions → «Сборка Android APK» → Run workflow; готовый APK появится в Artifacts. См. `КАК_ПОЛУЧИТЬ_APK.txt`.
